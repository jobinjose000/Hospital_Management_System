# 🏥 Hospital Management System

A full-stack Hospital Management System built with **Python and Django**.

This project is being developed as a complete healthcare management platform with role-based access for patients, doctors, laboratory staff, pharmacy staff, and administrators.

## 🚀 Project Status

Currently under active development.

### ✅ Completed

- Initial Django project setup
- MariaDB database configuration
- Public hospital homepage
- Custom user model
- Role-based user system
- Patient profile
- Doctor profile
- Laboratory staff profile
- Pharmacy staff profile

### ⏳ Planned Features

- Authentication and dashboards
- Appointment management
- Disease prediction
- Laboratory workflow
- Prescriptions and pharmacy management
- Payments
- SMS notifications
- Reports and disease verification
- Admin management
- Final UI integration
